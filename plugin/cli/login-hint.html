Use your password manager here: install it once in this login profile

The Shipment Tracker signs in through its own Chrome profile, separate from your everyday browser, so your password manager isn't here yet. Install it in this window once; it stays for every later login.

Get LastPass from the Chrome Web Store

Any password-manager extension works, e.g. 1Password or Bitwarden. Once one is installed, this tab no longer opens. The login page is the other tab.
